# Changelog

## 0.24.0

- **Glasshouse is now Panalume.** Same dashboard, new name (another Home Assistant dashboard has a very similar name). Install **Panalume** from this repository in the App Store; when it starts it copies your dashboard from Glasshouse automatically. Then point any wall tablets at Panalume and uninstall this app.
- Updating this app replaces Glasshouse with a page explaining the move; your dashboard is kept so Panalume can still copy it.
